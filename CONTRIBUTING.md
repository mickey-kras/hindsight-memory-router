# Contributing

## Public repository boundary

This repository is public and deployment-agnostic.

Do not include private infrastructure details, host names, vault names, account names, internal repository paths, personal workflows, or deployment-specific architecture in code, documentation, issues, pull-request titles, or pull-request descriptions.

Describe features using generic roles and interfaces. Keep environment-specific configuration and operational runbooks in the deployment repository that owns them.

Human-authored pull requests require normal review and manual merge. Dependabot automation is managed separately.
